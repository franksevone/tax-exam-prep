# 📚 แอปติวสอบสรรพากร (Tax Exam Prep)

เว็บติวข้อสอบสำหรับสอบคัดเลือก / อบรมบุคลากรด้านภาษีอากร — ครอบคลุมประมวลรัษฎากร, กฎหมายประกอบ, หลักการบัญชี และความรู้หน่วยงาน

## สารบัญเนื้อหา
- **ประมวลรัษฎากร**: ภาษีเงินได้บุคคลธรรมดา/นิติบุคคล, VAT, SBT, เบี้ยปรับ-เงินเพิ่ม, การอุทธรณ์, อำนาจเจ้าพนักงาน, บทกำหนดโทษ, มาตรา 40(1)-(8) ค่าใช้จ่าย
- **ภาษีอื่น ๆ**: ภาษีที่ดินและสิ่งปลูกสร้าง, ภาษีป้าย, สรรพสามิต, ศุลกากร, ภาษีการรับมรดก, e-Tax Invoice/e-Receipt
- **กฎหมายประกอบ**: จัดซื้อจัดจ้าง, บริหารราชการ, วินัยการเงินการคลัง, ข้อมูลข่าวสาร, PDPA, สารบรรณ, ข้าราชการพลเรือน, ป.พ.พ., ป.อาญา-คอมพิวเตอร์
- **แบบทดสอบ**: 34 ชุด โจทย์เก็งข้อสอบ + โจทย์ในบทเรียน รวม 238 ข้อ
- **เส้นทางการเรียนรู้ 0-100**: 63 ขั้น 8 ตอน เรียงจากพื้นฐานไปยาก พร้อมระบบความคืบหน้า (เรียนต่อ/รีเซ็ต/ติ๊กรายขั้น)

## สถิติปัจจุบัน (v3.2.0)
- หมวดเนื้อหา + โจทย์: 63 หมวด | โจทย์รวม: 238 ข้อ | ตัวบทกฎหมาย: 122
- เส้นทางการเรียนรู้: 63 ขั้น (ยาก 5-100) แบ่ง 8 ตอน

## วิธีใช้งาน
- คลิกหัวข้อในเมนูเพื่ออ่านบทเรียน / ทำแบบทดสอบ
- เมนู "เส้นทางการเรียนรู้ 0-100" (บนสุด) สำหรับเรียนตามลำดับพร้อมระบบความคืบหน้า
- คลิกหัวกลุ่ม "📖 เนื้อหา" / "📝 แบบทดสอบ" เพื่อย่อ-ขยายเมนู
- ฟีเจอร์ถาม AI ใช้ Gemini API key ส่วนตัว (แปะในแอปได้เลย ไม่มีการเก็บ key ไว้ที่ไหน)
- ข้อมูลความคืบหน้า/การตั้งค่าจำไว้ใน localStorage ของเบราว์เซอร์

เป็น static site ล้วน (HTML/CSS/JS) ไม่มี backend
